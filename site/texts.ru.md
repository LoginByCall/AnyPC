## Почему AnyPC

- `whyT`: Почему AnyPC
- `f1t`: Обходит любой NAT
- `f1d`: Соединяется напрямую, когда невозможно — через сервер-ретранслятор. Роутер настраивать не нужно.
- `f2t`: Сквозное шифрование
- `f2d`: Экран и ввод идут по DTLS-SRTP. Ретранслятор пересылает только шифротекст.
- `f3t`: Один исполняемый файл
- `f3d`: Одна программа показывает ваш ID и пароль и подключается к другим ПК. Установка не нужна.
- `f4t`: Плавно и отзывчиво
- `f4d`: Видео H.264 до 1080p, 30 кадров/с; качество подстраивается под канал, показывает статистику соединения в реальном времени.

### Windows

- `w1`: Запустите скачанный AnyPC.exe — установка не нужна, программа сразу показывает ID этого компьютера. При первом запуске она один раз скачает компонент FFmpeg (около 40 МБ).
- `w2`: Если появится «Система Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае»: программа пока не подписана сертификатом.
- `w3`: Если брандмауэр Windows спросит о доступе к сети — разрешите, иначе прямое соединение может не получиться и связь пойдёт через ретранслятор.
- `w4`: Чтобы к этому компьютеру можно было подключаться, задайте пароль в разделе «Это рабочее место».
- `wchk`: Проверить файл (PowerShell) — сумма должна совпасть с указанной выше:

```
Get-FileHash .\AnyPC.exe
```

### Linux

- `l1`: Установите зависимости — набор зависит от графической сессии:

```
# X11
sudo apt install ffmpeg xclip zenity
# Wayland
sudo apt install gstreamer1.0-pipewire gstreamer1.0-plugins-ugly wl-clipboard zenity
```

- `l2`: Сделайте файл исполняемым и запустите — окно AnyPC откроется во вкладке браузера:

```
chmod +x AnyPC-linux-amd64
./AnyPC-linux-amd64
```

- `l3`: В Wayland при первом подключении система спросит, какой экран показывать и можно ли управлять. Разрешение запоминается, повторно спрашивать не будет.
- `l4`: Чтобы завершить программу, нажмите «Выйти из AnyPC» во вкладке или Ctrl+C в терминале.
- `lchk`: Проверить файл — сумма должна совпасть с указанной выше:

```
sha256sum AnyPC-linux-amd64
```

## Начать за 3 шага

- `howT`: Начать за 3 шага
- `s1`: Скачайте AnyPC на компьютер, которым надо управлять, или на оба и запустите.
- `s2`: На компьютере, которым нужно управлять, задайте пароль (от 8 символов) и запишите его ID из 9 цифр.
- `s3`: В окне браузера или на другом компьютере введите этот ID и пароль и нажмите «Подключиться». Если на управляемом ПК включено подтверждение, там нужно нажать «Разрешить».

## Безопасность

- `secT`: Безопасность
- `sec1`: Любое подключение требует пароль, заданный на управляемом ПК; сам пароль по сети не передаётся.
- `secAsk`: Можно включить подтверждение: на каждое подключение управляемый ПК спрашивает «Разрешить / Отклонить», без ответа за 30 секунд — отказ.
- `sec2`: Во время сессии на управляемом ПК всегда видно уведомление с кнопкой разрыва.
- `sec3`: После 5 неверных паролей доступ временно блокируется.
- `sec4`: Используйте AnyPC только на своих компьютерах или с согласия владельца.
- `sec5`: Никогда не сообщайте ID и пароль тому, кто неожиданно вам позвонил, — это частая схема мошенников.

## Ограничения бета-версии

- `limT`: Ограничения бета-версии
- `lim1`: Ctrl+Alt+Del, окна UAC и экран блокировки пока недоступны.
- `lim2`: Буфер обмена — только текст; файлы передаются кнопками на панели.
- `lim3`: Несколько мониторов переключаются на панели; в Wayland монитор выбирается в системном окне при подключении.
- `lim4`: Версии для Linux и macOS — бета, проверены меньше, чем версия для Windows.

## Почему AnyPC — свой сервер

- `f5t`: Можно со своим сервером
- `f5d`: Поставьте свой узел на VPS одной командой и переключите программу на него — сведения о подключениях останутся у вас.
- `f6t`: Несколько ретрансляторов
- `f6d`: Серверы-ретрансляторы в Гонконге, Москве и США. Если напрямую соединиться не вышло, программа сама выберет самый быстрый путь по сумме пингов обеих сторон — или выберите сервер вручную.

## Свой сервер (VPS)

- `tab_srv`: Свой сервер
- `n1`: Свой узел AnyPC на вашем VPS: сигнализация, ретранслятор и веб-клиент на вашем домене — кто и когда подключался, знает только ваш сервер. Нужны VPS на Ubuntu или Debian с публичным IP и домен.
- `srvS`: На сервере
- `srvC`: На клиенте
- `n2`: В DNS добавьте запись A: домен → IP сервера (у Cloudflare — без проксирования, «серое облако»).
- `n3`: Выполните на сервере — скрипт скачает anypc-server, сверит контрольную сумму, откроет порты в ufw, настроит ретранслятор coturn и сертификат Let’s Encrypt. Если межсетевой экран у хостера (в панели управления), откройте там 80 и 443/tcp, 3478/tcp и udp, 49152–65535/udp. Обновление — той же командой:
- `n4`: В AnyPC на своих ПК: «Свой сервер» = ваш домен → «Сохранить». ID не меняется; с галочкой «оставаться и в сети AnyPC» ПК доступен и через серверы AnyPC.
- `n5`: Подключиться через другой узел, не меняя настроек: в поле ID — ID@домен, например 123456789@my.example.com. Веб-клиент узла — https://ваш-домен/.
- `n6`: Или вместо шага 2 — в Docker (NAS, сервер уже на Docker): в пустом каталоге выполните, подставив свой домен и IP сервера, и откройте те же порты сами. Если порты 80 и 443 заняты вашим обратным прокси, смотрите README на GitHub.

```
curl -fsSL https://hk.anypc.org/download/install.sh | sudo sh -s my.example.com
```
