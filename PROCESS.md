## Перед выпуском (релизный DoD)

Шаги, которые обычный `go test ./...` не покрывает: без них выпуск не готов.

- **Детектор блокировки экрана на Маке** (Э3, «Работаю тут»; app/lock_darwin.{go,m}): проверяется только
  `go test -tags lockprobe ./app -run MacLock -v` на Маке **с графическим сеансом** (пользователь вошёл в консоль;
  по ssh годится). Без графического сеанса тест пропускается (Skip) — это не «зелёный». Обычная сборка и
  `go test ./app` пробу не включают (тег `lockprobe`). Тест шлёт в сеанс настоящее `com.apple.screenIsLocked`
  (экран не блокируется); экран не блокировать и систему не менять. Ожидание: `--- PASS: TestMacLockLive`.
- **Детектор блокировки на Windows** (app/lock_windows.go): на машине с Windows `go test ./app -run TestLockWinLive -v`
  (окно и регистрация WTS настоящие, события шлёт сам тест). Стенда Windows пока нет — до него V1 только на Linux
  (TestLockAct, TestWTSDetector) и сборка `GOOS=windows go test -c ./app`; живые блокировка, сон и выключение — V2
  владельца (карточки ИЗМЕРЕНИЕ в отчёте Ч5).
