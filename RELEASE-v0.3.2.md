## AnyPC v0.3.2

**Отправить на свой ПК / Send to your PC**
- Файлы и папки — на любой ПК вашего пространства без сессии управления: экран «Отправить», «Отправить ›» в трее, избранные получатели. / Files and folders to any PC of your space without a control session: the "Send" screen, "Send ›" in the tray, favourite recipients.
- На чужой ПК — по его ID и коду; после первого раза отправитель запоминается, «Отозвать» убирает его. / To someone else's PC — by its ID and code; the sender is remembered after the first time, "Revoke" removes it.

**Пространство / Space**
- Вступление по шагам: в каждом состоянии написано, что происходит и что делать дальше. / Joining step by step: every state says what is going on and what to do next.
- Новый ПК вступает без пароля — по фразе пространства и коду; ваш ПК один раз спрашивает «Пустить ПК в пространство?». / A new PC joins without a password — with the space phrase and a code; your PC asks "Let this PC into the space?" once.

**Передать управление / Give control**
- Переключатель «Разрешить управление»: пока он выключен, одноразовый код не действует. После запуска программы — выключен. / "Allow control" switch: while it is off, the one-time code does not work. Off after the app starts.

**Исправления / Fixes**
- Linux: курсор доходит до края экрана при масштабировании, плашка сессии — узкая полоса. / Linux: the pointer reaches the screen edge under scaling, the session plaque is a narrow strip.

**Важно / Note**
- Чтобы вам помогли по коду, сначала включите «Разрешить управление». / To get help by code, turn on "Allow control" first.
- Вступление без пароля — когда на обоих ПК v0.3.2; с более старым ПК — прежний путь с паролем. / Password-less joining needs v0.3.2 on both PCs; with an older PC the password path is used.
- Не откатывайтесь на v0.2.0: старый сервер не передаёт «Снять». / Do not roll back to v0.2.0: the old server does not relay "Take off".
